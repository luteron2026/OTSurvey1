# OTSurvey1 — Old Testament Study Cards

A self-contained study site for an Old Testament Survey course. It turns the class notes into flashcards and practice quizzes, so you can drill the material class by class and before the midterm.

**Live site: [luteron2026.github.io/OTSurvey1](https://luteron2026.github.io/OTSurvey1/)**

## What's inside

- **Class Notes** — cards from each class session, grouped by book (Genesis, Exodus, Leviticus, Numbers). New cards are added after each class.
- **Midterm Review** — a separate set of cards for midterm prep.
- **Three ways to study** each set:
  - **Cards** — flip one at a time.
  - **List** — everything at once, grouped by book or section.
  - **Quiz** — pick what to study, then type your answers and grade yourself, or switch to multiple choice.
- **Card types** — definitions, facts, fill-in-the-blanks, lists, verses and references.
- **Progress** — mark cards as known and see how many you've learned.
- **Search** — find terms, phrases and Scripture references.
- **Light / dark theme.**

## Using it

There is nothing to install. Visit the [live site](https://luteron2026.github.io/OTSurvey1/) in any modern browser, on desktop or phone, or open `index.html` locally. The site is published with GitHub Pages from the `main` branch.

Your "known" marks and theme choice are saved in your own browser only.
